# Contributing

Open an issue describing the problem and affected screen ID. Design changes should include Russian and English labels and both display orientations. Use physical-button terminology and preserve optical alignment.

Do not commit credentials, private network information or unlicensed third-party assets. Mark hardware-dependent behavior as provisional until tested. Keep firmware claims separate from planned features.

For code contributions, add build instructions and relevant validation results when firmware exists. Submit focused pull requests with a concrete before/after description.
