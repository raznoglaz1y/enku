# Contributing to ENKU

Thanks for helping improve ENKU.

ENKU is an open-source pocket e-reader project that spans firmware, hardware, UI, documentation and enclosure design. Contributions do not need to be code.

## Good ways to contribute

- **Firmware** — reader behavior, input handling, display refresh, storage, power and performance.
- **Hardware** — board research, battery and power notes, component validation and reproducible wiring.
- **UI / UX** — screen flows, typography, physical-control interaction and accessibility.
- **Documentation** — build notes, setup instructions, diagrams, troubleshooting and proofreading.
- **Translations** — keep wording concise and suitable for a small E Ink display.
- **Testing** — reproduce bugs, test on real hardware and report exact steps and environment details.
- **Enclosure** — mechanical feedback, printable parts, tolerances and assembly improvements.

## Before starting

For bugs, ideas or substantial changes, open an issue first. This keeps work visible and helps avoid duplicated effort.

When reporting a bug, include:

1. What you expected.
2. What happened instead.
3. Steps to reproduce it.
4. Relevant hardware and firmware details.
5. Logs, screenshots or photos when useful.

## Pull requests

Keep pull requests focused on one change when practical.

Please include:

- a short explanation of the problem;
- what changed;
- how you tested it;
- screenshots, photos or logs for visible or hardware-related changes;
- any documentation that should change with the implementation.

Do not include secrets, private credentials, generated build artifacts or unrelated formatting changes.

## Project direction

ENKU aims to stay understandable, reproducible and practical to build from accessible parts. Prefer solutions that keep the project approachable over unnecessary complexity.

If a contribution changes hardware assumptions, navigation, file formats or build steps, document that impact clearly.
