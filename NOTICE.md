# Third-party assets and release prerequisites

The mockup boards use Noto Sans and user-supplied SVG icons. Original font/icon packages are not included in this initial repository package. Their source, license and required attribution must be recorded before public redistribution. Book text and illustrative covers in historical boards also require review for public release.

No final code/design license is granted by this package. Choose licenses with the project owner before publishing it as an open-source release.
