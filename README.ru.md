# ENKU

Проект открытой электронной читалки на Waveshare ESP32-S3 ePaper 3.97″.

**Текущий этап: макеты и спецификация UI. Рабочей прошивки в этом пакете ещё нет.**

Управление физическими кнопками; альбомная ориентация 800×480 и книжная 480×800; русский и английский интерфейс; шрифт чтения Noto Sans.

![Основные элементы](design/screens/ru/ENKU_ui_kit_core_v1.png)

Планируются библиотека список/сетка, поиск, фильтры, чтение с закладками, пять типографических пресетов, индивидуальные настройки книги, сон, сохранённые и доверенные Wi-Fi сети, импорт с карты и по Wi-Fi. USB требует выбора реализации.

[Каталог экранов](docs/screens.md) · [Карта переходов](docs/navigation.md) · [План](ROADMAP.md) · [Правила UI](docs/ui-spec.md)

[Слои интерфейса](design/renders/ui-layers-ru.svg) — концептуальная схема логической композиции, не схема аппаратной сборки.

Полный русский набор собран из последних доступных версий. Английский набор пока представлен проверочным макетом; перевод всех экранов — отдельный пункт плана. Ранние доски требуют проверки на устаревшие подписи и выравнивание.

Лицензия проекта будет выбрана до публичного релиза; лицензии сторонних иконок и шрифта проверяются отдельно.
