# ENKU commercialization + source-release strategy

Status: **superseded policy / October 2026**

This document originally defined a fully-open-from-day-one commercialization model.

The project strategy has changed.

Current policy: [release & openness policy](release-policy.md).

ENKU now uses a **delayed-open / selective-open** model:
- user ownership, repairability and local-first behavior remain core commitments;
- source/design files are released according to product maturity;
- production-sensitive engineering may remain private during active development;
- commercial kits and crowdfunding remain compatible with later public source releases.

The previous fully-open model is retained in Git history for transparency, but it is no longer the active policy.
