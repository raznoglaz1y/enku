# UI baseline

- Non-touch interface. Navigation moves focus; confirmation activates.
- Noto Sans; reading presets: Spacious, Comfortable, Standard (default), Compact, Dense. Manual changes select Custom.
- Both orientations use the same interaction model. Orientation is manual.
- Buttons and input fields: 48 px high. Corner radius 4 px. Normal border 1 px; focus border 2 px.
- Typical title 20 px bold; text 16 px; supporting label 12 px.
- Text optical vertical centre uses the lowercase x-height, excluding ascenders and descenders.
- Centre icons and trailing progress across the entire multi-line group.
- Header arrow 20 px with 12 px text gap. Dialog icon 24 px with 8 px gap; asymmetric icons require individual optical correction.
- Titles use at most two lines and then ellipsis; supporting labels use one line. Keep font size stable.
- Focus, selected setting and active tab are separate states.
- Keyboard uses icon keys. Shift once: next capital; twice: Caps Lock; third: lowercase.
- Modal height follows content. Restore parent focus and scroll on return.
- Global reading settings by default; optional settings for this book only.

Pixel values are a baseline from the approved component boards. Historical screens still require a consistency audit before implementation.
