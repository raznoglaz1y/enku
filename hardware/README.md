# ENKU hardware — public snapshot

**Public hardware development freeze:** October 2026  
**Snapshot head at policy transition:** `6f9cc8b7d036d55ea0e3e6687e241f3453178391`

ENKU has moved to a **delayed-open / selective-open** development model.

The hardware already present in this public repository remains part of the public project history. It is not rewritten or hidden retroactively.

From this point forward, production-sensitive Reader hardware work continues privately until the appropriate release gate.

Private by default:
- active PCB routing / placement;
- production schematic changes;
- Gerbers / drill / pick-and-place;
- factory-ready BOM and sourcing data;
- DFM / assembly optimization;
- test fixtures and production tooling.

This public tree may still receive selected stable hardware documentation and release snapshots later.

See: [Release & openness policy](../docs/release-policy.md).
