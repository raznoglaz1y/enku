DESIGN

Quiet interfaces for a slow display.

ENKU is designed around monochrome e-paper and physical controls from the start. The interface favors clear hierarchy, stable focus, predictable back behavior and content-first reading instead of borrowing interaction patterns from touch devices.

INTERACTION RULES

Behavior before decoration.

The visual language is intentionally restrained, but the more important design work is behavioral: what owns focus, what Back means, which state persists and when a display refresh is worth paying for.

01 · READING

Content first

Reader chrome stays hidden by default. Menus and Quick Aa appear as explicit overlays without changing the underlying semantic reading position.

02 · FOCUS

Visible ownership

Every navigable screen has one understandable focus path for physical controls; long lists preserve focus and scroll context rather than resetting the user.

03 · STATUS

Persistent essentials

Clock and compact system indicators are designed to remain legible without dominating the book or Library content.

04 · E INK

Refresh with intent

Layouts avoid animation assumptions. Visible transitions are grouped around meaningful state changes so full and partial refresh behavior can remain predictable.

05 · POSITION

Never lose the page

Typography and orientation changes preserve semantic reading position, then repaginate around that anchor instead of treating the current framebuffer as state.

READING PRESETS

Five useful defaults.

Typography presets change font size, line spacing and margins together. Manual adjustments move the book to Custom, while settings can remain global or be overridden for a single title.
